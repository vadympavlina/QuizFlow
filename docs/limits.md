# Панель лімітів (Адмінка → Ліміти)

Одна сторінка показує, скільки лишилось безкоштовних квот: Firebase, Cloudflare і AI-провайдери.
Дані збирає воркер (`GET /limits`, лише адміністратор), браузер ключів не бачить. Кожен блок працює окремо:
якщо щось не налаштовано, сторінка прямо каже що саме, а решта блоків працює.

## Firebase (база даних)
Показує сховище, завантаження за місяць і пік одночасних підключень відносно безкоштовної квоти (Spark: 1 ГБ, 10 ГБ/міс, 100 підключень).
Потрібен вже наявний секрет воркера `FIREBASE_SERVICE_ACCOUNT` і два кроки в Google Cloud:
1. <https://console.cloud.google.com/apis/library/monitoring.googleapis.com> → вибрати проєкт Firebase → **Enable** (Cloud Monitoring API).
2. IAM → службовий акаунт з ключа (`client_email`) → додати роль **Monitoring Viewer** (Переглядач Monitoring).

## Cloudflare (воркер і KV)
Показує запити до воркера і операції KV (читання, запис, видалення, списки) за поточну добу UTC відносно безкоштовного плану
(100 000 запитів, 100 000 читань, по 1 000 записів/видалень/списків).
1. Cloudflare → **My Profile → API Tokens → Create Token → Custom token**: право **Account → Account Analytics → Read**, обліковий запис — ваш.
2. Cloudflare → Workers → воркер → **Settings → Variables and Secrets → Secrets**: додати `CF_API_TOKEN` (токен) і `CF_ACCOUNT_ID` (Account ID з правої колонки дашборда).
3. (за потреби) `CF_SCRIPT_NAME` — ім'я воркера, якщо воно не `quizflow-mail`.

## AI (Groq і Gemini)
Додаткових налаштувань не потрібно, крім `FIREBASE_SERVICE_ACCOUNT`: воркер сам веде облік у базі (`aiProv/{день UTC}/{провайдер}`, читає лише воркер).
- **Groq** у кожній відповіді повідомляє свої ліміти й залишок: на сторінці видно запити за добу й токени за хвилину (станом на останній запит).
- **Gemini** залишок не повідомляє. Воркер показує кількість своїх запитів за день, помилки й відповіді 429 (ліміт перевищено). Щоб бачити смугу,
  задайте змінну воркера `GEMINI_DAILY_LIMIT` — скільки запитів на день дає ваша модель на вашому плані.
Облік лише рахує, на роботу AI він не впливає: якщо запис у базу не вдався, відповідь AI все одно приходить.
